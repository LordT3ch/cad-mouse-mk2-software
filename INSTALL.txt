CAD Mouse MK2 - instalace (English: INSTALL.en.txt)
===================================================
Novinky a zdrojáky: https://github.com/LordT3ch/cad-mouse-mk2-software

Požadavky: Windows 10/11 (x64) a WebView2 Runtime (ve Windows 11 už je; když ve Windows 10
zůstane okno aplikace prázdné, stáhni od Microsoftu "Evergreen Runtime").

1) Firmware
   - Podrž tlačítko BOOT na XIAO RP2040 a připoj USB.
   - Objeví se disk RPI-RP2. Zkopíruj na něj firmware\firmware.uf2.
   - Myš se sama restartuje.
   (firmware-generic-vid.uf2 = varianta bez USB ID 3Dconnexion, viz README na GitHubu.)

2) Ikonka u hodin
   - Rozbal tenhle zip do složky, kam se dá zapisovat (např. Dokumenty\CadMouseMK2),
     NE do Program Files - aplikace si vedle exe ukládá nastavení tlačítek.
   - Spusť tray\CadMouseTray.exe. U hodin se objeví ikonka.
   - Pravým na ikonku -> "Spouštět s Windows".
   - Windows SmartScreen může varovat, protože exe není podepsané:
     Další informace -> Přesto spustit.

3) Autodesk Fusion (volitelné, ve Fusionu nahradí 3DxWare)
   - Ve Fusionu: Shift+S -> záložka Add-Ins -> "+" -> vyber složku fusion-addin\CadMouseNav.
   - Zaškrtni "Run on Startup" a dej Run.
   - Když máš nainstalované i 3DxWare, vypni ve Fusionu buď 3DxWare, nebo tenhle doplněk,
     jinak se pohled hýbe dvakrát.

4) Kalibrace
   - Klikni levým na ikonku -> "Ladění a kalibrace".
   - Dej "Naučit všechny pohyby" a postupuj podle pokynů.
